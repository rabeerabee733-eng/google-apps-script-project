# تثبيت نسخة شخصية على iPhone باستخدام Windows

هذا المسار لتجربة تطبيق إدارة التحضير الأصلي بحساب Apple مجاني. ليس نشرًا على App Store أو تثبيتًا عامًا من Safari.

## بناء الملف

مسار GitHub Actions المسمى `iPhone IPA for AltStore` يستخدم جهاز macOS قياسيًا، ويعمل فقط عندما يكون المستودع عامًا. لا يستخدم اشتراك EAS أو حساب Apple أو شهادة مدفوعة. يعمل على تحديث طلب الدمج الذي يغيّر ملفات التطبيق، أو بالتشغيل اليدوي بعد إتاحة workflow في الفرع الافتراضي. لا تدمج تغييرات الخادم لتشغيل البناء فقط.

ينفذ تثبيت التبعيات المقفلة، وفحص TypeScript وESLint واختبارات العميل، ثم Expo prebuild وCocoaPods وXcode Release لأجهزة iPhone الحقيقية. يتحقق من معمارية ARM64 ووجود JavaScript المضمّن ومعرّف التطبيق قبل ضغطه داخل Payload.

إذا نجح البناء، نزّل artifact المسمى `altahdir-iphone-altstore` وفك ZIP. الملف المطلوب هو `altahdir-management-altstore-unsigned.ipa`. يحتفظ GitHub بالمخرج ليوم واحد فقط؛ احفظه قبل انتهاء المدة. وجود workflow لا يعني أن البناء نجح؛ افحص النتيجة أولًا.

## على كمبيوتر Windows

1. اتبع الدليل الرسمي: https://faq.altstore.io/altstore-classic/how-to-install-altstore-windows
2. ثبّت iTunes وiCloud من المصادر المحددة في الدليل، ثم AltServer.
3. وصّل الآيفون، وافق على الوثوق بالكمبيوتر وفعّل Wi-Fi Sync، ثم اختر Install AltStore من AltServer.
4. أدخل بيانات Apple بنفسك في أداة التوقيع على جهازك. لا تضعها في المستودع أو المحادثة.
5. اتبع خطوات الوثوق بحساب المطوّر وتفعيل Developer Mode عند طلبهما.
6. انقل IPA إلى تطبيق Files على الآيفون. من AltStore افتح My Apps ثم زر + واختر IPA، مع تشغيل AltServer وإمكان اتصال الهاتف به.

الملف غير موقع مسبقًا: يعيد AltStore توقيعه بحسابك. لا يمكن تثبيته بمجرد فتحه في Safari. التوقيع المجاني ينتهي بعد 7 أيام؛ يلزم تجديده عبر AltServer. الحد المعتاد ثلاثة تطبيقات موقعة مجانًا، ويشغل AltStore نفسه أحد الأماكن. لم تختبر هذه النسخة على جهاز المالك بعد.
